Created `Assets/Scripts/Grapple.cs` only; no other files touched.

**Implementation summary**
- `TryGrab`: gated on `hero.CanAct`, no current action/hold/thrown, `cooldown<=0`, left-arm stage `<3`; calls `FaceEnemy()`, then scans `Game.I.enemies` for the closest non-boss/non-elite/non-`Captured` living foe within forward `0..1.6` and `|dy|<1.6` that is either `hp<=maxHp*.5` or stunned. On success sets `Captured=true`, 3s hold, stores `hero.facing` as hold direction, `.8s` cooldown, and shows a Korean notice ("G로 던지거나, 정면 피해를 한 번 대신 막는다.").
- Per-frame while held: forces `hero.facing` to the stored direction and positions the captive at `hero.position + (dir*1, +0.25)`. Natural 3s expiry calls `Release()` (no damage, drop to ground, `Stun(.5)`, `Captured=false`).
- `AbsorbHit`: requires `CanAct && Holding`, a living `source != held`, and `source` in front of the stored direction (`dx*dir>=0`); releases the captive to the ground and routes the *full* damage through `held.TakeHit(damage, dir, .2f)` exactly once, then clears the hold. No player HP/trauma/parry/honor side effects.
- `Throw`: requires `Holding`, `CanAct`, left-arm `<3`; launches the captive in the stored direction at speed 12 for up to 0.6s, y pinned near `.25`, x clamped to `[-18,18]`. A swept segment check each frame picks the first other living, non-`Captured` enemy within `|dy|<1.6` and a 0.8 radius ahead of travel. On hit (or timeout/boundary): `Captured` is cleared and the actor is dropped to the ground *before* any damage; the struck enemy takes `24`/`.6` stagger via `TakeHit`, then the thrown actor always takes a single `20`/`.8` self-hit via `TakeHit` (Enemy's own stagger≥.5 rule naturally applies `Stun(.8)` if it survives) — no duplicate hits.
- `Cancel`/`ResetState`: safe to call repeatedly, release both `held` and `thrown` without dealing end-of-flight damage, drop them to the ground, clear `Captured`/state; wired to `OnDisable`/`OnDestroy`. `ResetState` = `Cancel()` + `cooldown=0`.
- Frozen time (`Game.I.Frozen`) short-circuits `Update()` entirely, pausing hold/flight/cooldown ticking. Leaving `Phase.Combat` or crossing left-arm stage 3 triggers `Cancel()` on the next frame. Destroyed/dead `held`/`thrown` refs are guarded via Unity's null-equality and `Alive` checks each frame to avoid repeated damage on externally killed captives.

**Caveats / dependencies not implemented here (explicitly Codex's scope per instructions)**
- This file references `Enemy.Captured` (bool) and expects `Barbarian.grapple` to host this component — neither exists yet in the current `Fighters.cs`, so the project **will not compile** until Codex adds `public bool Captured` to `Enemy` (and blocks `Enemy.Update` when `Captured`), adds `public Grapple grapple` to `Barbarian` (and instantiates it, e.g. via `AddComponent`), wires the `G` key to `TryGrab`/`Throw`, excludes `Holding` from attack/dash/parry/headbutt/jump, and calls `Cancel()`/`ResetState()`/`AbsorbHit` as described.
- I have not run Unity or any shell/tests — no build or play-mode verification was performed, per instructions.
- Visuals/sound reuse only existing `Game.Burst`/`Game.Sound` helpers (simple spark burst + tone on throw impact); no new assets or view/HUD edits.
