Windows PC / Unity 6000.6.0f1

시작
압축을 모두 푼 뒤 Valhalla.exe를 실행합니다. Valhalla_Data, DLL과 다른 동봉 폴더는 함께 두세요.
로비 → 잿빛 항구 → 오른쪽 훈련장(E) → 준비 → 오른쪽 관문(E)으로 출정합니다.
마을의 가공·판매·문신·장비 안내는 자유 순서입니다. Tab으로 자세한 설명을 볼 수 있습니다.

어떤 게임인가
몸의 7부위에 문신을 장착해 싸움법을 만듭니다. 공격·회피·패링·처치에 따라 능력이 발동합니다.
부상 30에서는 자동 적응으로 강해지지만 위험도 커집니다. 55에서는 해당 부위의 모든 문신이 침묵합니다.
회복약은 HP만 회복합니다. 부상은 다음 출정에서 복구됩니다. 적응 선택창은 없습니다.

조작
A/D 이동 · Space 점프 · J/좌클릭 일반 공격 · K/우클릭 강공격
C 패링 · Shift 대시 · Q 박치기(생명 4) · V 잡기/투척
E 시설/관문/상호작용 · I 소지품 · Tab 상세 UI · Esc 메뉴
강공격은 즉시 준비하고 0.43초 뒤 타격합니다. 버튼을 오래 누를 필요가 없습니다.
시선은 적을 향하지만 대시는 이동 입력을 우선합니다. 입력이 없으면 바라보는 쪽으로 갑니다.
방어 입력은 0.25초 보관하며 타격을 마친 공격의 마지막 0.12초 후딜에서 전환할 수 있습니다.
공격 입력은 0.15초 보관합니다. 너무 일찍 누르면 만료됩니다. Tab은 전투를 멈추지 않습니다.

처음 비교할 두 구성
1) 기본 천둥 + 피의 룬(35은화) + 질주(40은화): 강공격·처치 회복·대시 충돌.
2) 피의 룬(35) + 반격(45): 오른팔 천둥을 해제하고 반격을 장착해 패링 충격파를 사용합니다.
두 구성 모두 시작 은화 80으로 준비할 수 있습니다. 문신은 소유와 장착을 구분합니다.

모험과 귀환
잿빛 숲 → 부러진 광산 → 망자의 성소. 각 지역에서 보급로/정예 경로를 골라 총 9방을 진행합니다.
방 정리 후 안전 귀환하면 부산물 전부, 사망하면 종류별 절반을 보관합니다.
가죽·뼈·금속을 대장간에서 가공하고 장비/연고를 제작하거나 상인에게 판매합니다.
마을 준비와 소유품은 저장됩니다. 출정 중 방 진행은 저장되지 않으며 종료 시 미보관 전리품을 잃습니다.

설계가 적용된 곳
MDA: 문신 발동·자동 부상·귀환 손실(규칙) → 싸움법/위험/귀환 선택(행동) → 몸으로 만드는 빌드와 긴장감(경험).
절차적 생성: SeededDungeonGenerator가 시드별 적·함정·상자를 배치합니다. 갈림길 구조는 고정이며 무작위 지형 조립은 아닙니다.
SOLID: BodyRules는 부상/문신 판정, EconomyService는 거래, IProfileStore는 저장 계약을 맡습니다.
JSON/메모리 저장은 같은 계약으로 교체하며 EconomyService는 저장 구현을 주입받습니다. 전체 코드의 완전한 DI 전환을 뜻하지 않습니다.
상태 머신: 전투 Phase와 적의 접근/예고/타격/회복. Strategy: 생성/전리품 계약. Observer: 문신 발동 신호로 UI·음향·월드 연출 연결.
풀링: 문신 선 연출 6개·음향 8개 재사용. 화면·애니메이션은 전투 규칙과 분리합니다.
자세한 소스 위치와 협업 기록은 Unity 프로젝트의 README.md에 있습니다. Claude Code CLI와 Codex가 공동 작업했습니다.

검증과 남은 조정
캠페인 297개·전투 21개·빌드 전 규칙 12개 통과. 이후 마을/상자 표시 변경은 최종 빌드와 화면으로 확인했습니다.
두 시드/두 문신 구성의 자동 전투 3회는 각각 세 지역 9방 승리·귀환을 확인했습니다(이전 0.13 전투 규칙 기준).
자동 검사는 실제 키보드 조작감이나 사람의 이해도를 증명하지 않습니다. 패링·대시·UI에 대한 사용자 피드백을 0.15에 반영했고 새 체감은 추가 확인 대상입니다.
일부 동작은 컷아웃 자세 보간이며 적 외형은 공통 시트 변형입니다. 음악/환경음과 나머지 문신 전용 연출은 추가 제작 대상입니다.
